# Customer Segmentation Project

## Project Overview
This project performs customer segmentation using Machine Learning and Power BI visualization.

## Tools & Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Power BI

## Features
- Data preprocessing
- Customer behavior analysis
- K-Means clustering
- Customer segmentation
- Interactive Power BI dashboard

## Dataset
Mall Customers Dataset

## Project Workflow
Dataset → Python Analysis → K-Means Clustering → Segmented Dataset → Power BI Dashboard

## Output
- Customer segments
- Business insights
- Interactive dashboard
