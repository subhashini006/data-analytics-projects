📊 Sales & Revenue Dashboard

📌 Overview

This project is a Power BI dashboard analyzing sales and revenue performance.

📂 Dataset

Includes:

* Date
* Product
* Sales
* Profit (used as Revenue)

📊 Features

* KPI Cards (Total Sales & Revenue)
* Sales by Product (Bar Chart)
* Revenue Trend (Line Chart)
* Interactive Slicers (Product & Date)

🧹 Data Cleaning

* Removed duplicates
* Handled missing values
* Corrected data types

📈 Insights

* Identified top-performing products
* Analyzed revenue trends over time
